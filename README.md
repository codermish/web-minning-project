# AI-Powered Resume-Based Job Recommender

This project implements a web-based job recommender system using web mining and NLP to automatically match resume skills with live job listings.

## 🔍 Features

- Resume upload in PDF or DOCX
- Skill extraction via regex pattern matching
- Web scraping from:
  - [RemoteOK](https://remoteok.com)
  - [Remotive.io](https://remotive.io)
- Real-time skill matching and scoring
- Filtered results with interactive table
- Streamlit dashboard with CSV export

## 🧰 Tech Stack

- **Python** (backend logic)
- **Streamlit** (dashboard interface)
- **BeautifulSoup** (HTML parsing)
- **PyPDF2**, **python-docx** (text extraction)
- **Pandas**, **Regex**

## 📁 How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

Upload your resume and receive ranked job recommendations based on your skills.
